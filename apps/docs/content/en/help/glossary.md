Cluster uses consistent terminology across its interface, emails, certificates, and exports in both English and Spanish. Product (**Cluster**) and module names (**CONNECT**, **KNOW**, **GROW**, **LIFE**) are never translated.

| English | Spanish | Meaning |
|---|---|---|
| Area | Área | A node in the organization tree; may have a designated manager. |
| Assignment | Asignación | A mandatory GROW course assigned to a person, area, or position, or a member's placement in an area/position. |
| Attempt | Intento | One submission of a GROW quiz. |
| Certificate | Certificado | A PDF issued upon completing a GROW course with certificate issuance enabled. |
| Course | Curso | A structured training unit in GROW containing sections, lessons, and quizzes. |
| Draft | Borrador | An unpublished KNOW page visible only to Editors and Managers. |
| Due date | Fecha límite | Optional deadline on a mandatory GROW assignment. |
| Lesson | Lección | A text, video link, uploaded video, or file step inside a GROW course. |
| Main node | Nodo principal | A top-level area in the organization tree (internal or external). |
| Manager (area) | Responsable | Person designated to lead an area and view its GROW compliance reports. |
| Manager (space) | Gestor | Space role with permission to edit space settings, files, and sharing. |
| Member | Miembro | A person belonging to an organization. |
| Position | Puesto | A job role in the organization's catalog. |
| Quiz | Cuestionario | An assessment step in a GROW course. |
| Recovery code | Código de recuperación | Single-use code to sign in if your 2FA authenticator device is unavailable. |
| Session | Sesión | An active signed-in device or browser. |
| Space | Espacio | A container for KNOW pages and files with its own access list. |
| Two-step verification (2FA) | Verificación en dos pasos | TOTP authenticator-app verification required on sign-in. |
