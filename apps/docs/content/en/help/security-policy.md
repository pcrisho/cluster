We take the security of Cluster and self-hosted instances seriously.

## Reporting a vulnerability

If you discover a security issue in Cluster, please report it privately rather than opening a public issue:

- Include a clear description of the vulnerability and the affected component or endpoint.
- Provide steps to reproduce or a minimal proof of concept.
- Avoid accessing or modifying data belonging to other users or organizations.

We will acknowledge your report, investigate the issue, and coordinate a fix before public disclosure.
