Released on **2026-11-23** (`v0.1.0`). First public open-core release of Cluster under the MIT license.

## Added

- **KNOW**: spaces, per-space access roles (`Viewer`, `Editor`, `Manager`), realtime collaborative editing, version history with diffs, Markdown import/export, inline image and PDF viewer, and search.
- **GROW**: courses, text/video-link/file/uploaded-video lessons, quizzes with optional manual review, mandatory assignments by person/area/position, PDF certificates with public verification, and compliance reports with CSV export.
- **CONNECT**: member directory, interactive organization chart, feed, and celebrations.
- **Administration & Core**: organization settings, bulk `.xlsx` member import, areas and positions, instance and organization themes, and full English/Spanish localization.

## Security

- PostgreSQL Row-Level Security (`tenant` policy) across organization-scoped tables with separate application and system database roles.
- TOTP two-step verification (2FA) with recovery codes, Postgres-backed sessions, adaptive login throttling, and nonce-based CSP.
