title: Glosario
description: Definiciones de los términos principales usados en Cluster en español e inglés.
section: help
order: 2
---

Cluster mantiene una terminología coherente en toda la interfaz, correos, certificados y exportaciones en español e inglés. El nombre del producto (**Cluster**) y los de los módulos (**CONNECT**, **KNOW**, **GROW**, **LIFE**) nunca se traducen.

| Español | Inglés | Significado |
|---|---|---|
| Área | Area | Un nodo en el árbol organizacional; puede tener un responsable designado. |
| Asignación | Assignment | Un curso obligatorio de GROW asignado a una persona, área o puesto, o la ubicación de un miembro en un área/puesto. |
| Borrador | Draft | Página de KNOW sin publicar, visible solo para Editores y Gestores. |
| Certificado | Certificate | PDF emitido al completar un curso de GROW con emisión de certificado activa. |
| Código de recuperación | Recovery code | Código de un solo uso para iniciar sesión si no tienes tu dispositivo de 2FA. |
| Cuestionario | Quiz | Paso de evaluación dentro de un curso de GROW. |
| Curso | Course | Unidad formativa estructurada en GROW con secciones, lecciones y cuestionarios. |
| Espacio | Space | Contenedor para páginas y archivos de KNOW con su propia lista de acceso. |
| Fecha límite | Due date | Plazo opcional en una asignación obligatoria de GROW. |
| Gestor (espacio) | Manager (space) | Rol de espacio con permiso para editar configuración, archivos y acceso del espacio. |
| Intento | Attempt | Cada envío de un cuestionario en GROW. |
| Lección | Lesson | Paso de texto, enlace de video, video subido o archivo dentro de un curso de GROW. |
| Miembro | Member | Persona que pertenece a una organización. |
| Nodo principal | Main node | Área de nivel superior en el árbol organizacional (interno o externo). |
| Puesto | Position | Rol laboral en el catálogo de la organización. |
| Responsable (área) | Manager (area) | Persona designada para liderar un área y ver sus informes de cumplimiento en GROW. |
| Sesión | Session | Dispositivo o navegador con sesión iniciada. |
| Verificación en dos pasos (2FA) | Two-step verification (2FA) | Verificación con app TOTP requerida al iniciar sesión. |
